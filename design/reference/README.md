# Design reference

FormCraft visual direction is encoded in `src/app/globals.css` design tokens:

- Primary cobalt `#183fe6` / container `#3d5cff`
- Surface `#f8f9ff`
- Editorial paper `#F4F1EA` / alt `#E8E3D8`
- Libre Caslon Text (headlines) + Hanken Grotesk (body)
- Paper shadow `4px 4px 0 rgba(14,15,17,0.1)`

HTML mockups supplied during product definition (Today Command Centre, Research Feed, Script Studio, Brand Brain, etc.) are the source of the shell and editorial patterns. Runtime UI is React + Tailwind — not CDN HTML pages.
